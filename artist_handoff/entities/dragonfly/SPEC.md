## 1. What this mob is (AUTHORED — draft for the owner's edit)

A large passive dragonfly: a thorax with a head, two jaws, antennae, six jointed legs, a two-part tail and four long wings. It hunts small prey on the wing and is otherwise calm. Read it as a fast four-winged flyer with a slowly working mouth.

## 4. Current animation behaviour — plain English and the source formulas

- Several independent rhythms run at all times, none scaled by walking speed; the classic code has no rest pose. The transcription ships idle (no bone) plus one clip per rhythm: the primary group (`primary_group`; the first group when the seed names none) carries the bare `walk` - a label, not a semantic: the contract's fly -> walk fallback is what plays a flyer's walk in flight (owner 2026-09-13, addendum item 26 (2)) - and every other rhythm is `walk_<group>`, so the GeckoLib candidate plays the transcription behind the switch.
- Two rhythms: the fast wing beat (the primary group: its clip is the bare walk) and the slow jaws; legs, tail, head and antennae are static.
- The default renderer poses it from the classic code; the GeckoLib candidate sits behind the dev switch (-Dorespawn.dev.geckolibRenderers) and your clips replace the shipped transcription file for file.

### 4.2 The math

- **wings**: the four wings beat fast about the body's long axis: front-left up while front-right is down, the rear pair the same shape turned half round — `lfwing.zRot = cos(ageInTicks * 1.3 * 2.0) * pi * 0.25; rfwing.zRot = -(that); lrwing.zRot = that + 3.14; rrwing.zRot = -(that) + 3.14` (DragonflyModel.java:211-214; DragonflyGeoReplacement.java)
- **jaws**: the two jaws open and close slowly, mirrored (they bind tilted 0.436 rad about X, the keys carry the delta) — `ljaw.xRot = cos(ageInTicks * 0.3 * 2.0) * pi * 0.1; rjaw.xRot = -(that)` (DragonflyModel.java:215-216; DragonflyGeoReplacement.java)
