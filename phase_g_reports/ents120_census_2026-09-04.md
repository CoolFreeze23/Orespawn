## 0. The convention, stated once

- 1.7.10: `EntityPlayer.yOffset = 1.62`; `Entity.setPosition` hung the bounding box `yOffset` below `posY`, so a
  player's `posY` was its eye level (standing) and every other entity's `posY` its feet. `getDistanceSqToEntity`,
  `getDistanceSq(x,y,z)`, `getDistanceToEntity`, `(int) e.posY`, `e.posY - posY` all read that field.
- Port (1.21.1): `getY()`, `position()`, `blockPosition()`, `distanceToSqr(entity)`, `distanceTo(entity)` are the feet
  for every entity; `getEyeY()` is the eyes.

## 5. Helper API proposal — `danger.orespawn.util.OrigPos`

```java
package danger.orespawn.util;

/** 1.7.10 position frame: a player's posY was its eye level (EntityPlayer.yOffset = 1.62), every other entity's its feet. */
public final class OrigPos {
    private OrigPos() {}
    /** 1.7.10 EntityPlayer.yOffset. */
    public static final double PLAYER_Y_OFFSET = 1.62;

    /** orig {@code e.posY}. */
    public static double y(Entity e) { return e.getY() + (e instanceof Player ? PLAYER_Y_OFFSET : 0.0); }

    /** orig {@code (int) e.posY} — the truncating cast of every flight target / block lookup (y >= 0 in 1.7.10; at
     *  negative y the cast and floor differ by one — documented, owner's pick; proposal: keep the cast). */
    public static int blockY(Entity e) { return (int) y(e); }

    /** orig {@code a.getDistanceSqToEntity(b)}. Symmetric; a may be the player (interact sites). */
    public static double distSq(Entity a, Entity b) {
        double dx = a.getX() - b.getX(), dy = y(a) - y(b), dz = a.getZ() - b.getZ();
        return dx * dx + dy * dy + dz * dz;
    }
    /** orig {@code a.getDistanceSq(x, y, z)} — a's frame against a raw point (containers, sit anchors). */
    public static double distSq(Entity a, double x, double yy, double z) {
        double dx = a.getX() - x, dy = y(a) - yy, dz = a.getZ() - z;
        return dx * dx + dy * dy + dz * dz;
    }
    /** orig {@code a.getDistanceToEntity(b)} — float, as orig. */
    public static float dist(Entity a, Entity b) { return (float) Math.sqrt(distSq(a, b)); }
    /** orig {@code a.posY - b.posY} (rings, up/down tests, holds). */
    public static double dy(Entity a, Entity b) { return y(a) - y(b); }
}
```
